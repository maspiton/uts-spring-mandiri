## 1. Topik Spring (5W)
* What (Apa): Framework open-source berbasis Java untuk mengembangkan aplikasi web dan enterprise.
* Why (Mengapa): Menyederhanakan pengembangan dengan fitur Dependency Injection (DI) dan Inversion of Control (IoC) agar kode lebih rapi dan modular.
* When (Kapan): Digunakan saat membangun proyek berskala menengah hingga besar yang membutuhkan skalabilitas dan integrasi luas.
* Who (Siapa): Diciptakan oleh Rod Johnson, kini dikelola oleh Pivotal (VMware), dan digunakan oleh jutaan developer Java.
* Where (Di mana): Aplikasi dapat di-deploy dan dijalankan di berbagai lingkungan seperti server lokal, container (Docker), hingga cloud.
